# Бекап мода (полная копия рабочей папки)

Снято 23.10.2026 перед обновлением игры.

- `root/` файлы из корня папки игры (`Start_Game_With_OSD.bat`, `CLAUDE.md`, фото-референс эффекта поражения)
- `OSD_Overlay/` вся папка мода как была: exe v20, config.ini, исходник, шаблоны, вспомогательные утилиты, лог
- `OSD_Overlay/old/` самая первая версия от предыдущей попытки

## Под какую сборку игры

Мод привязан к конкретному билду `FPVKamikazeDrone-Win64-Shipping.exe`:

- размер 176902656 байт, дата файла 07.05.2026
- UE 5.5, GWorld RVA 0xA219D88, GObjects 0x9DB24E0, FNamePool 0x9FAB2C0

На другой версии игры эти адреса почти наверняка съедут, мод надо будет перепривязать.

## Как вернуть

Скопировать `OSD_Overlay/` в корень игры, `root/Start_Game_With_OSD.bat` туда же, запускать через батник.
Не попали в бекап (мусор/огромное): `osd_dump.txt` 95 МБ, `.obj`, `diag_game.exe`, FModel, UE4SS (стоковый, не установлен в игру).
