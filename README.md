# FPV Kamikaze OSD

Внешний мод для игры **FPV Kamikaze Drone** (Unreal Engine 5.5): заменяет стандартный HUD дрона-камикадзе на OSD в стиле реальных FPV-дронов и делает картинку с камеры ближе к настоящей.

Мод ничего не внедряет в процесс игры и не меняет её файлы. Это отдельная программа-оверлей, которая читает память игры и рисует OSD поверх окна.

## Что умеет

**OSD (только на камикадзе)**
- Таймер полёта, высота, тангаж, газ, ток, расход mAh, напряжение банки и сборки, RXg/TXg
- Газ, батарея, высота и тангаж берутся из игры, электрика считается по модели 6S
- Белый прицел и линия горизонта из точек, которая наклоняется по крену и тангажу
- На разведчике и Striker OSD не показывается, в меню и на паузе прячется

**Камера дрона**
- Родной HUD камикадзе полностью скрыт
- Картинка на весь экран без чёрных полос (в игре камера зажата в 4:3)
- Без помех и без глушения РЭБ (оптоволокно)
- Разрешение камеры 720p, растянутое на экран
- При поражении цели последний кадр застывает на 0.7 с, потом появляется экран «Visible / NO IMAGE», как на реальном приёмнике. Сама игра в это время идёт дальше

**Мир**
- Уничтоженная техника не исчезает до конца катки
- Взрывы не подкидывают технику, урон не меняется
- Растительность и мелочь рисуется до 500 м с плавным появлением, дальше видны деревья и тени

## Установка

1. Скачай архив из [Releases](../../releases) или папку `OSD_Overlay` из репозитория.
2. Положи папку `OSD_Overlay` куда угодно, например в папку с игрой.
3. Запусти `OSD_Overlay\FPV_OSD_Overlay.exe`, потом игру как обычно. Можно и в обратном порядке: оверлей сам найдёт игру и закроется вместе с ней.
4. Игру лучше держать в **оконном полноэкранном** (безрамочном) режиме. В эксклюзивном полноэкранном оверлей может не отображаться, а заморозка кадра при ударе даст чёрный экран.

Если положить `Start_Game_With_OSD.bat` в корень папки игры (рядом с папкой `FPVKamikazeDrone`), он запустит оверлей и игру одним кликом.

Если игра запущена от администратора, оверлей тоже нужно запускать от администратора.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| F6 | Показать / скрыть OSD (родной HUD при этом возвращается) |
| F7 | Сбросить таймер и mAh |
| F8 | Включить / выключить графические правки (для сравнения) |
| F9 | Записать диагностический дамп в `osd_dump.txt` |

## Настройки

Всё лежит в `OSD_Overlay\config.ini`. Основное:

- `[OSD]`: шрифт, размер, `AltitudeRelative=1` даёт высоту от точки старта вместо уровня моря карты, `UseTemplateImage=1` возвращает старый OSD-шаблон картинкой
- `[Hud]`: `CameraHeight` (720 по умолчанию, 0 выключает), `KeepWrecks`, `KnockbackScale` (0 без отбрасывания, 1 как в игре), `NoInterference`, `FoliageMinCullDistance` в сантиметрах (50000 = 500 м)
- `[Impact]`: время заморозки, время экрана NO IMAGE, прозрачность серого, `Enable=0` выключает эффект
- `[CVars]`: консольные переменные движка, которые оверлей выставляет сам. Если проседает FPS, уменьши `FoliageMinCullDistance`, `r.Shadow.DistanceScale` и подними `r.Nanite.MaxPixelsPerEdge`

Если что-то не работает, смотри `osd_log.txt` рядом с exe.

## Совместимость

Адреса движка (GWorld, GObjects, FNamePool) жёстко привязаны к конкретной сборке `FPVKamikazeDrone-Win64-Shipping.exe`. После обновления игры они могут поменяться, тогда в логе будет предупреждение `exe differs`. Всё остальное (смещения свойств) мод находит сам через рефлексию движка.

Мод рассчитан на одиночную игру. Он пишет в память игры (скрытие HUD, камера, обломки, взрывы, растительность), поэтому в сетевой игре используй его на свой страх и риск.

## Сборка из исходников

Исходник в `src/main.cpp`, без Windows SDK и без CRT, только Win32 API и GDI+.

- **MSVC:** `src\build_msvc.bat` (поправь путь к `vcvars64.bat`)
- **clang + lld (в том числе на Linux):** `cd src && bash build.sh`, нужны `clang++`, `lld-link` и `llvm-dlltool` для сборки import-библиотек из `lib/*.def`:
  ```
  for l in kernel32 user32 gdi32 gdiplus; do llvm-dlltool -m i386:x86-64 -d lib/$l.def -l lib/$l.lib; done
  ```
